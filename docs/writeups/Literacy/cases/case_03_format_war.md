# Case 3: The Format War

**The Scenario:** You are a graphic designer using a MacBook. You create a brilliant report in Apple Pages and email the `.pages` file to your client. Your client, who uses a Windows PC, replies: "I can't open this. It says the file type is unsupported."

**The Question:** Why can't the client's Operating System open your file? 

**Your Task:** Explain the concept of file extensions (the letters after the dot, like `.pdf` or `.docx`). What should you do to ensure anyone, regardless of their OS, can read your report?
