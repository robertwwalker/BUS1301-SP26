# Case 2: The Airplane Edit



**The Scenario:** You are about to board a 5-hour flight with no Wi-Fi. Your boss sends you a link to a Google Doc and says, "Please review and edit this on the plane."

**The Question:** If you just close your laptop, board the plane, and open the link mid-flight, what will happen? 

**Your Task:** Explain the difference between a cloud file (Google Doc) and a local file (Microsoft Word doc saved to your desktop). What must you do *before* the airplane doors close to ensure you can work?
